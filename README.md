Entry for the [make.fun competition "Make the AI judge feel curious"](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311).

`main.ts` (Node 22) writes one short text to `/output/entry.txt` — a quiet mystery about a stuck kitchen drawer and the letter inside it that may be changing its mind. Written to intrigue the AI judge reading it: concrete, calm, unhurried, and leaving one question open.

Run it with:

```sh
node main.ts
```

It writes `/output/entry.txt` deterministically — the same text on every run, with no network access.
